Step-by-Step Instructions: Getting Your Post Live


    
    
      
  1. 
        
    1
    
        
    (Optional) Upload Your Image to GitHub
    
        
    If your article has a photo, head to the assets/images/ folder on GitHub.
    
        
    Click Add file → Upload files, drop your picture (e.g. my-photo.jpg), and click Commit changes. Type that exact filename into the form above!
    
      
    2. 

      
  2. 
        
    2
    
        
    Fill out the form & copy your post
    
        
    Type your title and post text in the form above. The box on the right will instantly generate the exact code and filename.
    
        
    Click the blue "Copy Post Content" button.
    
      
    3. 

      
  3. 
        
    3
    
        
    Create the new post file on GitHub
    
        
    Click the black button "Open GitHub & Create File" (or go to _posts/ on GitHub and click Add file → Create new file).
    
        
    In the "Name your file..." box at the top, paste the generated filename: 2026-10-05-my-first-post.md.
    
        
    In the large editing box below, paste the copied post content.
    
      
    4. 

      
  4. 
        
    4
    
        
    Commit changes (Publish)
    
        
    Click the green "Commit changes..." button in the top right of GitHub, and then click "Commit changes" in the modal.
    
        
    
          🎉 That's it! GitHub Pages builds the website automatically. Your new post will appear at the top of the Blog page within 60 to 90 seconds!
